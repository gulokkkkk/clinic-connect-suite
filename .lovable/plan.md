# Dental Clinic Frontend Redesign

## Goal
Turn the empty first screen into a polished, animated, one-clinic dental experience based on the approved product documentation and the new clinic-specific frontend specification.

## What will be built
- A distinct fictional dental clinic identity with clear demo labelling.
- A responsive public homepage with clinic-first introduction, urgent guidance, services and indicative PKR rates, fictional dentists, booking preview, care journey, sterilization/trust, FAQ, and contact placeholders.
- Real interactions for service selection, booking preview, FAQ, and mobile navigation using synthetic data only.
- Purposeful tooth and section animation with reduced-motion support.
- Complete page metadata and accessible desktop, tablet, and mobile behavior.

## Design process
1. Lock the palette, typography, and page structure through visual choices.
2. Produce three rendered directions using those choices and the current-screen capture.
3. Implement the selected direction precisely in the existing TanStack Start and Tailwind v4 project.
4. Verify layout, interactions, console health, and responsive behavior in the running preview.

## Boundaries
- This milestone designs the public clinic experience; it does not claim the planned production backend, staff workspaces, payments, messaging, or medical records are connected.
- All clinic, clinician, schedule, and price details remain clearly fictional or indicative until replaced with verified clinic information.
- No credentials, medical data, or tenant authority will be placed in the browser.
